# Security policy

The project is not deployed and has no production users. Security claims and audit status have not been established.

Do not report a suspected vulnerability in a public issue. Before public repository launch, maintainers must enable GitHub private vulnerability reporting or publish a monitored security contact. Until that is available, do not send credentials or sensitive payment data through GitHub; contact the repository owner through the GitHub organization profile.

The planned integration must treat SDP API keys, ERPNext credentials, payment identifiers, recipient information, and transaction data as sensitive. Never commit secrets or real user/payment records. Reported vulnerabilities should include affected version, reproduction steps using synthetic data, and impact, without attaching live credentials or customer records.

No independent security audit has been performed.
