# Community standards

We follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Participants are expected to be respectful, constructive, and focused on the work. Harassment, discriminatory conduct, doxxing, and sharing private credentials or payment data are not acceptable.

Report conduct concerns privately to the repository owner through the GitHub organization profile. Do not post personal or financial data in a public report.
